# Проверка на Windows

Чек-листы для ручной проверки каждого этапа на реальном компьютере с Windows.

## Как скачать и установить сборку

**Релиз** (основная версия, обновляется сама): скачайте `XonkyPass_<версия>_x64-setup.exe`
со страницы [Releases](https://github.com/tokumei1912-byte/XonkyPass/releases/latest)
и запустите. Дальше приложение обновляется автоматически, см. [UPDATES.md](UPDATES.md).

**Тестовая сборка ветки** (без автообновления):

1. Откройте вкладку [Actions](https://github.com/tokumei1912-byte/XonkyPass/actions) репозитория.
2. Выберите последнюю успешную сборку (зелёная галочка) нужной ветки.
3. Внизу страницы в разделе **Artifacts** скачайте `XonkyPass-setup-…` и распакуйте zip.
4. Запустите `XonkyPass_<версия>_x64-setup.exe`.
   Если Windows покажет окно SmartScreen, нажмите «Подробнее» → «Выполнить в любом случае»
   (установщик пока не подписан сертификатом).

## Как сообщить о проблеме

Напишите номер пункта, который не прошёл, и что произошло. По возможности приложите скриншот
и последний файл журнала из `%LOCALAPPDATA%\XonkyPass\logs\`
(путь можно вставить в адресную строку Проводника).

## Этап 0. Каркас

Установка:

- [ ] 0.1. Установщик запускается и ставит приложение без запроса прав администратора.
- [ ] 0.2. В конце установки можно сразу запустить XonkyPass.

Трей:

- [ ] 0.3. В трее появилась иконка (может быть спрятана под стрелкой `^` у часов).
- [ ] 0.4. При наведении на иконку видна подсказка «XonkyPass».
- [ ] 0.5. Левый клик по иконке показывает окно, повторный клик прячет его.
- [ ] 0.6. Правый клик открывает меню: «Открыть», «Поиск», «Выход».
- [ ] 0.7. «Поиск» открывает второе окно (поле поиска) по центру экрана.

Окна:

- [ ] 0.8. В окне написано «версия 0.1.0» — значит, интерфейс связан с Rust.
- [ ] 0.9. `Esc` прячет окно.
- [ ] 0.10. Окна **не** видны в панели задач и в `Alt+Tab`.
- [ ] 0.11. Окно можно перетащить, взявшись за верхнюю часть с логотипом.
- [ ] 0.12. `Alt+F4` только прячет окно, иконка в трее остаётся.
- [ ] 0.13. Тема окна (светлая/тёмная) совпадает с темой Windows.

Запуск и выход:

- [ ] 0.14. Повторный запуск XonkyPass из меню «Пуск» не создаёт вторую иконку в трее, а показывает окно.
- [ ] 0.15. «Выход» в меню трея закрывает приложение, иконка исчезает.
- [ ] 0.16. В `%LOCALAPPDATA%\XonkyPass\logs\` есть файл журнала со строкой «запуск XonkyPass».

Удаление:

- [ ] 0.17. Приложение удаляется через «Параметры → Приложения» без ошибок.

## Этап 2. Основной интерфейс

Хранилище лежит в `%APPDATA%\XonkyPass\`. Чтобы пройти первый запуск заново, закройте
XonkyPass через трей и переименуйте эту папку.

Первый запуск:

- [ ] 2.1. При первом запуске окно предлагает создать мастер-пароль (шаг 1 из 2).
- [ ] 2.2. Под паролем видна шкала надёжности; «Далее» недоступна, пока пароль слабый
      или повтор не совпадает.
- [ ] 2.3. На шаге 2 показан ключ восстановления: «Копия» копирует его, «Файл» открывает
      окно сохранения Windows и сохраняет `.txt`, «Печать» открывает печать только с ключом.
- [ ] 2.4. «Открыть хранилище» доступна только после галочки «Ключ сохранён».
      После неё — пустой список с кнопками «Новый пароль» и «Новая заметка».

Записи:

- [ ] 2.5. `Ctrl+N` или «+ Пароль»: в поле пароля уже стоит сгенерированный пароль,
      шкала показывает «надёжный».
- [ ] 2.6. Кнопка с ползунками открывает генератор: длина, наборы символов, «без похожих»,
      парольная фраза. «Использовать» подставляет результат в запись. Настройки генератора
      запоминаются.
- [ ] 2.7. Теги: при вводе `ра` предлагаются существующие теги и «Создать тег»;
      `Enter` или запятая добавляют тег, `Backspace` в пустом поле убирает последний.
- [ ] 2.8. Если название пустое, оно берётся из сайта (`github.com` → «Github»).
- [ ] 2.9. `Ctrl+S` сохраняет запись и открывает её карточку.
- [ ] 2.10. `Ctrl+E` в карточке открывает правку; если что-то изменить и нажать `Esc`,
      появляется вопрос «Не сохранять изменения?».
- [ ] 2.11. `Ctrl+Shift+N` — новая заметка. Кнопки на панели и `Ctrl+B`/`Ctrl+I`/`Ctrl+K`
      вставляют разметку, `Enter` в пункте списка продолжает список. «Просмотр» показывает
      оформленный текст. `#тег` в тексте после сохранения появляется среди тегов заметки.
- [ ] 2.12. Звёздочка в карточке добавляет запись в избранное; фильтр «Избранное» в списке её показывает.

Список и клавиатура:

- [ ] 2.13. Набор текста в списке сразу ищет по названию, логину, сайту, тегам.
- [ ] 2.14. Стрелки выбирают запись, `Enter` копирует пароль, `Shift+Enter` — логин,
      `Ctrl+Enter` открывает карточку, `Delete` переносит в корзину.
- [ ] 2.15. Правый клик по записи (или клавиша меню) открывает меню действий.
- [ ] 2.16. Сочетания работают и в русской раскладке.

Буфер обмена:

- [ ] 2.17. После копирования пароля внизу виден тост с обратным отсчётом; через 20 секунд
      буфер пуст (`Ctrl+V` в Блокноте ничего не вставляет), появляется «Буфер очищен».
- [ ] 2.18. Скопированный пароль **не** появляется в журнале буфера `Win+V`.
- [ ] 2.19. Если до очистки скопировать в буфер что-то своё, XonkyPass его не стирает.
- [ ] 2.20. В настройках срок очистки меняется (например, 10 секунд) и сразу действует.

Корзина:

- [ ] 2.21. После «В корзину» появляется тост с «Отменить» — запись возвращается.
- [ ] 2.22. В корзине запись можно восстановить или удалить навсегда (с подтверждением);
      «Очистить» удаляет всё.

Блокировка и пароль:

- [ ] 2.23. `Ctrl+L` или кнопка с замком блокирует хранилище; неверный пароль — понятная ошибка,
      верный — снова список.
- [ ] 2.24. При вводе мастер-пароля с включённым Caps Lock или в русской раскладке видна подсказка.
- [ ] 2.25. «Забыли пароль?» → ввод ключа восстановления → новый мастер-пароль → хранилище открыто.
- [ ] 2.26. В настройках «Сменить» мастер-пароль работает; после блокировки открывается новым паролем.
- [ ] 2.27. «Создать новый» ключ восстановления: старый ключ больше не подходит, новый — подходит.

Вид:

- [ ] 2.28. На Windows 11 фон окна полупрозрачный (Mica), на Windows 10 — сплошной.
- [ ] 2.29. Цвет кнопок совпадает с цветом акцента Windows («Параметры → Персонализация → Цвета»);
      после смены акцента окно подхватывает его при следующем показе.
- [ ] 2.30. Тема в настройках («Как в Windows», «Светлая», «Тёмная») меняется сразу.
- [ ] 2.31. В настройках «Показать» открывает Проводник с выделенным файлом хранилища.
- [ ] 2.32. Ссылка на сайт в карточке открывается в браузере по умолчанию.

## Этап 3. Поиск, теги, избранное

Для проверки удобно иметь 10–20 записей с несколькими тегами, пару заметок и пару
записей в избранном.

Поиск:

- [ ] 3.1. Поиск нечёткий: `gthb` находит GitHub, `ПОЧТА` — «Почта», `елка` — «Ёлка».
      Лучшее совпадение сверху (совпадение в названии выше, чем в логине).
- [ ] 3.2. Слово из текста заметки находит заметку.
- [ ] 3.3. Несколько слов — находятся записи, где есть все слова.
- [ ] 3.4. Запрос в другой раскладке (`пшерги`) находит GitHub, над списком написано
      «В другой раскладке: «github»».
- [ ] 3.5. `#` в поиске показывает подсказки тегов с количеством; стрелки выбирают,
      `Enter` или `Tab` подставляют. `#работа #dev` — записи с обоими тегами.
- [ ] 3.6. `is` показывает подсказки `is:login`, `is:note`, `is:fav`; `has:totp` —
      записи с 2FA.
- [ ] 3.7. Ничего не найдено — видна подсказка о синтаксисе поиска.

Избранное, недавние, порядок:

- [ ] 3.8. Без запроса список разбит на «Избранное», «Недавние» (скопированные за неделю,
      не больше 5) и «Все записи».
- [ ] 3.9. `Ctrl+D` добавляет выбранную запись в избранное и убирает из него.
- [ ] 3.10. Кнопка со стрелками справа от чипов меняет порядок: по совпадению, по названию,
      недавно изменённые, часто используемые. Выбор сохраняется после перезапуска.
- [ ] 3.11. По названию: сначала русские названия по алфавиту, потом латинские.

Теги:

- [ ] 3.12. На чипах тегов видно число записей; клик по чипу — фильтр, `Esc` снимает его.
- [ ] 3.13. Правый клик по чипу тега: «Переименовать…» меняет тег во всех записях
      (и в тексте заметок `#тег`), «Удалить тег…» убирает его отовсюду, записи остаются.
- [ ] 3.14. Переименование в уже существующий тег предлагает объединить теги; после слияния
      у тега одно написание.
- [ ] 3.15. Чип «Теги…» открывает экран тегов: поиск по тегам, `Enter` — записи с тегом,
      `F2` — переименовать, `Del` — удалить.
- [ ] 3.16. Переименованный тег у записей в корзине тоже меняется (видно после восстановления).

Клавиатура:

- [ ] 3.17. Без мыши: `Tab` доходит до чипов, `←` `→` двигают по ним, `Enter` выбирает,
      `Shift+F10` открывает меню тега; `Ctrl+F` возвращает в поиск.
- [ ] 3.18. `Esc` по шагам: закрывает подсказки, очищает поиск, снимает фильтр, прячет окно.
- [ ] 3.19. После диалогов (переименование, удаление тега) фокус возвращается туда, где был.

Вид:

- [ ] 3.20. Выпадающие списки в настройках («Очищать через», «Тема») и в генераторе
      («Разделитель») открываются в стиле приложения, работают стрелками и `Enter`.

## Автообновление

Проверяется на релизной сборке (со страницы Releases).

- [ ] U.1. В подсказке иконки трея видна версия, например «XonkyPass 0.1.12».
- [ ] U.2. В меню трея есть пункт «Проверить обновления». Если новой версии нет, после нажатия
      он меняется на «Обновлений нет — проверить снова».
- [ ] U.3. После выхода нового релиза: «Проверить обновления» → появляется окно установки
      с прогрессом, приложение закрывается и само запускается снова с новой версией
      (видно в подсказке трея и в окне).
- [ ] U.4. Без нажатия: если приложение запущено и окна спрятаны, новая версия ставится сама
      в течение пары минут после запуска (или в течение 4 часов, если приложение уже работало).
- [ ] U.5. В журнале есть строки «найдено обновление» и «установка обновления».

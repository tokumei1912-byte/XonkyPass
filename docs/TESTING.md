# Проверка на Windows

Чек-листы для ручной проверки каждого этапа на реальном компьютере с Windows.

## Как скачать и установить сборку

1. Откройте вкладку [Actions](https://github.com/tokumei1912-byte/XonkyPass/actions) репозитория.
2. Выберите последнюю успешную сборку (зелёная галочка) нужной ветки.
3. Внизу страницы в разделе **Artifacts** скачайте `XonkyPass-setup-…` и распакуйте zip.
4. Запустите `XonkyPass_<версия>_x64-setup.exe`.
   Если Windows покажет окно SmartScreen, нажмите «Подробнее» → «Выполнить в любом случае»
   (установщик пока не подписан сертификатом).

## Как сообщить о проблеме

Напишите номер пункта, который не прошёл, и что произошло. По возможности приложите скриншот
и последний файл журнала из `%LOCALAPPDATA%\XonkyPass\logs\`
(путь можно вставить в адресную строку Проводника).

## Этап 0. Каркас

Установка:

- [ ] 0.1. Установщик запускается и ставит приложение без запроса прав администратора.
- [ ] 0.2. В конце установки можно сразу запустить XonkyPass.

Трей:

- [ ] 0.3. В трее появилась иконка (может быть спрятана под стрелкой `^` у часов).
- [ ] 0.4. При наведении на иконку видна подсказка «XonkyPass».
- [ ] 0.5. Левый клик по иконке показывает окно, повторный клик прячет его.
- [ ] 0.6. Правый клик открывает меню: «Открыть», «Поиск», «Выход».
- [ ] 0.7. «Поиск» открывает второе окно (поле поиска) по центру экрана.

Окна:

- [ ] 0.8. В окне написано «версия 0.1.0» — значит, интерфейс связан с Rust.
- [ ] 0.9. `Esc` прячет окно.
- [ ] 0.10. Окна **не** видны в панели задач и в `Alt+Tab`.
- [ ] 0.11. Окно можно перетащить, взявшись за верхнюю часть с логотипом.
- [ ] 0.12. `Alt+F4` только прячет окно, иконка в трее остаётся.
- [ ] 0.13. Тема окна (светлая/тёмная) совпадает с темой Windows.

Запуск и выход:

- [ ] 0.14. Повторный запуск XonkyPass из меню «Пуск» не создаёт вторую иконку в трее, а показывает окно.
- [ ] 0.15. «Выход» в меню трея закрывает приложение, иконка исчезает.
- [ ] 0.16. В `%LOCALAPPDATA%\XonkyPass\logs\` есть файл журнала со строкой «запуск XonkyPass».

Удаление:

- [ ] 0.17. Приложение удаляется через «Параметры → Приложения» без ошибок.

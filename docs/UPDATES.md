# Автообновление

Установленный XonkyPass сам обновляется из [GitHub Releases](https://github.com/tokumei1912-byte/XonkyPass/releases).
Переустанавливать приложение вручную не нужно.

## Как это работает

1. Каждый push в `main` (например, слияние pull request) запускает CI. Если проверки прошли,
   CI собирает подписанный установщик и публикует релиз `v0.1.N`
   (`N` — номер запуска CI, поэтому каждая следующая версия новее).
2. Приложение проверяет `latest.json` последнего релиза через 15 секунд после запуска
   и дальше раз в 4 часа.
3. Найденная версия скачивается в фоне. Её подпись сверяется с открытым ключом,
   встроенным в приложение (`plugins.updater.pubkey` в `src-tauri/tauri.conf.json`).
   Файл с неверной подписью не устанавливается.
4. Когда окна XonkyPass спрятаны около минуты, запускается установщик: он закрывает
   приложение, ставит новую версию и запускает её. Прав администратора не нужно.

В меню трея есть пункт **«Проверить обновления»**: проверяет и сразу ставит новую версию.
В нём же видно состояние: загрузка, готово к установке, ошибка.
Текущая версия показана в подсказке иконки трея.

**Тестовые сборки не обновляются.** Установщики из артефактов CI веток (`claude/…`) и локальные
сборки собираются без автообновления — иначе сборка, поставленная для проверки, сразу заменилась бы
релизом. В меню трея у них написано «Тестовая сборка: без автообновления». Чтобы вернуться на
релизы, установите последний установщик со страницы Releases.

## Настройка (один раз)

Релизы подписываются закрытым ключом. CI берёт его из секретов репозитория.

1. Откройте [Settings → Secrets and variables → Actions](https://github.com/tokumei1912-byte/XonkyPass/settings/secrets/actions)
   и нажмите **New repository secret**.
2. Добавьте два секрета:

   | Name                                 | Secret                    |
   | ------------------------------------ | ------------------------- |
   | `TAURI_SIGNING_PRIVATE_KEY`          | содержимое файла ключа    |
   | `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | пароль ключа              |

3. Сохраните ключ и пароль в надёжном месте. **Если ключ потерять, выпустить обновление для уже
   установленных копий будет нельзя** — придётся сделать новый ключ и один раз переустановить
   приложение вручную.

Без секретов сборка `main` падает с понятной ошибкой, сборки веток работают как обычно.

### Новый ключ

Если ключ утерян или скомпрометирован:

```bash
npx tauri signer generate -w xonkypass-updater.key
```

Содержимое `xonkypass-updater.key.pub` впишите в `plugins.updater.pubkey`
в `src-tauri/tauri.conf.json`, секреты замените новыми. Установленные копии со старым ключом
новые релизы не примут — их нужно один раз переустановить вручную.

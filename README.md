# XonkyPass

Быстрый локальный менеджер паролей и защищённых заметок для Windows.
Живёт в трее, прячется за край экрана и выезжает при подведении мыши.

> **Статус:** ранняя разработка. Подробный план — [docs/PLAN.md](docs/PLAN.md).

## Возможности

- **Всегда под рукой.** Иконка в трее. Панель прячется за верхний, левый или правый край экрана и выезжает, когда к нему подводят мышь. Есть режим «закрепить».
- **Быстрое добавление пароля.** Горячая клавиша работает из любого приложения. Сервис подставляется автоматически (активное приложение или сайт в браузере), пароль генерируется сам, Enter сохраняет.
- **Быстрые заметки.** Своя горячая клавиша, текст в Markdown.
- **Привязка к сервисам.** Запись связывается с сайтами (по домену) и приложениями (по exe). Если вызвать поиск в браузере на github.com, сразу показываются записи GitHub.
- **Поиск.** Мгновенный нечёткий поиск по названию, логину, сайту и тексту заметок. Фильтр по тегам: `#работа #банки`.
- **Безопасность.** Всё шифруется локально (Argon2id + XChaCha20-Poly1305). Автоблокировка, очистка буфера обмена. Пароли не попадают в историю буфера Windows и на скриншоты. Разблокировка через Windows Hello.
- **Удобства.** Генератор паролей, коды 2FA (TOTP), история паролей, корзина, автоматические резервные копии, импорт из KeePass, Bitwarden и браузеров.
- **Без облака.** Данные хранятся только на вашем компьютере.

## Горячие клавиши по умолчанию

| Клавиши          | Действие                     |
| ---------------- | ---------------------------- |
| `Ctrl+Alt+Space` | Поиск (палитра по центру)    |
| `Ctrl+Alt+P`     | Новый пароль                 |
| `Ctrl+Alt+N`     | Новая заметка                |
| `Ctrl+Alt+L`     | Заблокировать                |

Все сочетания меняются в настройках.

## Стек

| Часть                 | Технология                                        |
| --------------------- | ------------------------------------------------- |
| Ядро, шифрование, БД  | Rust                                              |
| Оболочка приложения   | Tauri 2 (трей, окна, горячие клавиши)             |
| Интерфейс             | Svelte 5 + TypeScript + Vite                      |
| Хранилище             | SQLite (rusqlite), шифрование на уровне записей   |
| Отображение           | WebView2 (встроен в Windows 10/11)                |
| Работа с Windows      | Win32 API через крейт `windows`                   |

## Требования

Windows 10 22H2 или Windows 11, x64.

## Безопасность в двух словах

- Мастер-пароль нигде не хранится. Из него через Argon2id получается ключ, который открывает ключ хранилища.
- Каждая запись зашифрована отдельно (XChaCha20-Poly1305) и привязана к своему идентификатору, поэтому подменить или переставить записи незаметно нельзя.
- Пароли расшифровываются только в Rust и только по запросу. Копирование в буфер идёт напрямую из Rust, минуя интерфейс.
- **Если забыть мастер-пароль и не сохранить ключ восстановления, данные вернуть невозможно.**

Подробности — в [docs/PLAN.md](docs/PLAN.md#2-данные-и-шифрование).

## Сборка из исходников

Что нужно установить:

1. Rust: https://rustup.rs
2. Node.js 22 LTS или новее: https://nodejs.org
3. Microsoft C++ Build Tools (Visual Studio 2022, компонент «Разработка классических приложений на C++»)
4. WebView2 Runtime (в Windows 11 уже есть)

```bash
npm install
```

```bash
npm run tauri dev
```

```bash
npm run tauri build
```

Установщик появится в `target/release/bundle/nsis/`.

Проверки перед коммитом:

```bash
npm run format:check && npm run lint && npm run check
```

```bash
cargo fmt --all -- --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace
```
